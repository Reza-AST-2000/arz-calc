# ابزار‌ها 🧰

یک اپلیکیشن وب پیشرونده (PWA) شامل محاسبه‌گر مالی و مجموعه‌ای بزرگ از ابزارهای کاربردی روزمره — کاملاً آفلاین، بدون بک‌اند، تک‌فایل (فقط HTML/CSS/JS خالص داخل یک `index.html`). در حال حاضر **۴۳ ابزار** در ۴ دسته‌بندی پیش‌فرض داخل اپه.

## امکانات کلی

**چیدمان و پیمایش**
- سه تب اصلی: **خانه**، **ماشین‌حساب**، **ابزارها** — با انیمیشن فید ملایم موقع جابه‌جایی بین تب‌ها و باز/بسته‌شدن هر ابزار.
- صفحه‌ی خانه با ساعت دیجیتال زنده (شمسی + میلادی + قمری، با ثانیه‌شمار)، حلقه‌ی پیشرفت روز جاری تو ماه، و پس‌زمینه‌ای که بر اساس ساعت روز (صبح/ظهر/عصر/شب) تغییر رنگ می‌ده.
- **حالت فشرده (Compact Mode):** ردیف‌های ابزار کوچیک‌تر و بدون توضیح، برای دیدن آیتم بیشتر تو یک صفحه.
- **چیدمان واکنش‌گرا:** روی تبلت و دسکتاپ، عرض اپ و تعداد ستون‌های لیست ابزارها خودکار بر اساس عرض واقعی صفحه تنظیم می‌شه (نه بر اساس تشخیص نوع دستگاه).
- نوار دکمه‌های بالای صفحه (بروزرسانی، تاریخچه، تنظیمات، وضعیت اتصال) بسته به تب فعال، فقط دکمه‌های مرتبط رو نشون می‌ده.
- صفحه‌ی splash با انیمیشن لوگو موقع باز شدن اپ.

**ماشین‌حساب**
صفحه‌نمایش اختصاصی، تاریخچه‌ی محاسبات، کپی/جای‌گذاری سریع (این صفحه‌نمایش فقط تو تب ماشین‌حساب دیده می‌شه).

**جست‌وجو و دسته‌بندی**
- جست‌وجوی ابزار با کلیدواژه‌های فارسی و انگلیسی.
- دسته‌بندی قابل‌ویرایش: ساخت دسته‌بندی دلخواه، تغییرنام/حذف، و جابه‌جایی ابزارها بین دسته‌ها با کشیدن (Drag & Drop).
- میان‌برهای پرکاربرد: پین‌کردن ابزار دلخواه با ⭐ برای دسترسی سریع بالای صفحه.

**حریم خصوصی و امنیت**
- **قفل ورود به اپ** با نام‌کاربری/رمز عبور (قفل نمایشی سبک، نه امنیت واقعی رمزنگاری‌شده).
- **حالت مرور خصوصی موقت:** با یک سوییچ، تاریخچه‌ی محاسبات، اسکن/ساخت QR و آمار استفاده از ابزارها موقتاً ثبت نمی‌شن؛ با بستن یا رفرش اپ خودکار خاموش می‌شه.
- رمزنگاری واقعی متن با AES-256-GCM، همراه با قابلیت تعیین **تاریخ انقضا برای پیام** (پیام حتی با رمز درست هم بعد از انقضا باز نمی‌شه) و آرشیو محلی یادداشت‌های انقضا (بدون ذخیره‌ی محتوای پیام).

**آفلاین و بروزرسانی**
- آفلاین واقعی با سرویس‌ورکر: بعد از اولین بازدید همه‌چیز کش می‌شه و بدون اینترنت هم کار می‌کنه (به‌جز ابزارهایی که ذاتاً به سرویس بیرونی نیاز دارن).
- نشانگر آنلاین/آفلاین بالای صفحه (تو هر ۳ تب) و هشدار مخصوص تو ابزارهایی که به اینترنت نیاز دارن.
- بررسی خودکار نسخه‌ی جدید: با نصب نسخه‌ی جدید فایل‌ها روی سرور، یه نوار «نسخه‌ی جدید موجوده» بالای صفحه و یه بج قرمز رو دکمه‌ی تنظیمات ظاهر می‌شه.
- نشونگر «آخرین بروزرسانی» کنار دکمه‌ی 🔄، و شماره‌ی نسخه‌ی «درباره‌ی برنامه» که خودکار از `sw.js` خونده می‌شه (نیازی به آپدیت دستی نداره).

**ظاهر**
چند پوسته‌ی رنگی (تیره/روشن/اقیانوسی/جنگلی/آمولد)، حالت کنتراست بالا، اندازه‌ی فونت و پس‌زمینه‌ی گرادیانی قابل‌تنظیم.

## دسته‌بندی‌های پیش‌فرض و ابزارها (۴۳ ابزار)

**🧮 محاسبات کاربردی** (۹ ابزار)
BMI (شاخص توده بدنی)، محاسبه‌ی سن (شمسی)، تبدیل تاریخ جامع (شمسی/میلادی/قمری)، درصدگیری، مبدل واحدها (طول، وزن، حجم، دما، حافظه، سرعت اینترنت، آشپزی)، مبدل سیستم‌های عددی (دهدهی/دودویی/هگزادسیمال/اکتال)، فاصله بین دو تاریخ/ساعت، ساعت جهانی (چند شهر هم‌زمان + نقشه‌ی مینی + بهترین ساعت تماس مشترک)، معدل و رتبه‌ی کنکور (تقریبی)

**💰 مالی و روزمره** (۱۲ ابزار)
وام و اقساط، سود سپرده بانکی، تقسیم صورت‌حساب گروهی (دنگی)، سود و زیان معامله، تورم و کاهش ارزش پول، قیمت متری و ساختمانی، حباب سکه و طلا، محاسبه‌ی مهریه‌ی سکه‌ای، تبدیل ارز، دخل‌وخرج ماهانه (با نمودار روند خرج ماهانه)، تخفیف و مالیات، اشتراک‌های ماهانه (نتفلیکس، اسپاتیفای، هاست... با یادآور تمدید و جمع هزینه)

**🔐 QR و امنیت** (۷ ابزار)
ساخت QR کد (وبسایت/متن/وای‌فای/پیامک/تماس/واتساپ/اینستاگرام/تلگرام/کارت‌ویزیت/ایمیل/لوکیشن/رویداد) با رنگ و لوگوی دلخواه، اسکن زنده‌ی QR با دوربین، رمز عبور قوی (تا ۵۰۰ کاراکتر)، مخفی‌سازی متن در عکس (استگانوگرافی)، رمزنگاری متن (AES-256 + تاریخ انقضا)، ساخت بارکد خطی (Code128)، نمایش اطلاعات IP

**🛠️ ابزارهای متفرقه** (۱۵ ابزار)
امضای دیجیتال (خروجی PNG شفاف)، پاک‌سازی و مرتب‌سازی لیست، استخراج متن از عکس (OCR)، کد مورس (فارسی/انگلیسی + پخش صدا)، چک‌لیست‌های آماده (سفر/کمپینگ) + آیتم دلخواه، قرعه‌کشی و تصمیم‌گیری (تاس، شیر یا خط، چرخ‌گردون)، یادآوری انقضای مدارک، حساب ابجد، تبدیل عدد فارسی/انگلیسی، دفترچه‌ی کارکرد و سرویس خودرو، هزینه‌ی سفر با ماشین، مناسبت‌های ایرانی (ملی/باستانی/مذهبی/فرهنگی/فصلی با شمارش معکوس)، یادآور تولد، **مرکز یادآوری** (تجمیع مدارک+تولد+اشتراک تو یه لیست)، آمار استفاده از اپ (این ماه / کل مدت)

> کاربر می‌تونه از تب «ابزارها» دسته‌بندی جدید بسازه و ابزارها رو بین دسته‌ها جابه‌جا کنه؛ لیست بالا فقط چینش پیش‌فرضه.

## اجرای محلی
هر سروری کافیست، مثلاً:
```bash
python3 -m http.server 8080
```
سپس آدرس `http://localhost:8080` را باز کنید.

> نکته: برای نصب PWA (Add to Home Screen) و کارکرد Service Worker، باید از طریق `http://localhost` یا `https` باز شود — نه با باز کردن مستقیم فایل (`file://`).

## انتشار روی GitLab Pages
1. یک پروژه جدید در GitLab بسازید، مثلاً به اسم `abzarha`.
2. فایل‌های این پوشه را داخل ریپو کپی کنید و پوش کنید:
   ```bash
   git init
   git remote add origin git@gitlab.com:USERNAME/abzarha.git
   git add .
   git commit -m "بروزرسانی ابزار‌ها"
   git push -u origin main
   ```
3. فایل `.gitlab-ci.yml` (اگه همراه پروژه باشه) به‌طور خودکار سایت را روی GitLab Pages منتشر می‌کند؛ در غیر این صورت کافیه یه پایپ‌لاین ساده‌ی «کپی فایل‌ها به `public/`» بسازید.
4. بعد از اتمام پایپ‌لاین، آدرس سایت این شکلی خواهد بود:
   `https://USERNAME.gitlab.io/abzarha/`
5. برای نصب اپ روی گوشی: آدرس بالا را در مرورگر (Chrome/Safari) باز کنید و گزینه‌ی «افزودن به صفحه اصلی / Install App» را بزنید.

## ساختار پروژه
```
abzarha/
├── index.html          ← کل اپ (ساختار + استایل + منطق همه‌ی ابزارها)
├── sw.js                ← Service worker (کش آفلاین + تشخیص نسخه‌ی جدید)
├── manifest.json        ← تنظیمات PWA (نام، آیکون، تم رنگی)
├── README.md            ← همین فایل
└── icons/
    ├── icon-192.png      ← آیکون اپ (۱۹۲×۱۹۲)
    ├── icon-512.png      ← آیکون اپ (۵۱۲×۵۱۲)
    └── apple-touch-icon.png ← آیکون صفحه‌ی اصلی آیفون
```
> `manifest.json` و پوشه‌ی `icons/` باید حتماً کنار `index.html` و `sw.js` روی سرور باشن؛ سرویس‌ورکر همه‌ی این فایل‌ها رو در نصب اولیه کش می‌کنه و اگه یکیشون گم باشه، نصب سرویس‌ورکر (و درنتیجه حالت آفلاین) ممکنه با خطا مواجه بشه. مسیر آیکون‌ها هم تو `index.html` (تگ‌های `<link>`) و هم تو `manifest.json` باید به `icons/` اشاره کنه.

## افزودن ابزار جدید
همه‌چیز داخل `index.html` است؛ برای اضافه‌کردن یک ابزار جدید باید **۵ جا** رو هماهنگ کرد (فراموش‌کردن هرکدوم یعنی ابزار تو لیست دیده می‌شه ولی باز نمی‌شه یا کار نمی‌کنه):
1. یک آیتم به آرایه‌ی `toolsIndex` اضافه کنید (`id`, `icon`, `color`, `name`, `desc`, `kw`).
2. آیدی ابزار را در `DEFAULT_TOOL_CAT` به یکی از ۴ دسته‌ی پیش‌فرض نگاشت کنید.
3. یک ورودی متناظر در `TOOL_META` اضافه کنید (برای نمایش صحیح در میان‌برهای پین‌شده، آمار استفاده و مرکز یادآوری).
4. یک آیکون SVG با `id="ic-{id}"` به بلوک `<symbol>`ها اضافه کنید (اختیاری، اگه از یه آیکون emoji ساده استفاده نمی‌کنید).
5. یک بلوک `<div class="toolpage" id="tool-{id}">…</div>` برای HTML و فرم‌های ابزار بنویسید، توابع محاسبه/منطق ابزار را در تگ `<script>` اضافه کنید، و در صورت نیاز به مقداردهی اولیه (رندر لیست، پر کردن سلکتور تاریخ و…)، یک شرط برای `name=='{id}'` داخل تابع بزرگ `openTool()` اضافه کنید.

بعد از هر تغییر، نسخه‌ی `CACHE_NAME` در `sw.js` را یکی بالا ببرید (مثلاً `v113` → `v114`) تا کاربرها نسخه‌ی جدید را به‌جای کش قدیمی بگیرند؛ عدد نمایش‌داده‌شده تو «درباره‌ی برنامه» خودکار از همین مقدار خونده می‌شه.

## یادداشت
- ابزارهای «نمایش اطلاعات IP» و «استخراج متن از عکس (OCR)» (فقط بار اولی که موتورش دانلود می‌شه) برای کارکرد کامل به اتصال اینترنت نیاز دارند؛ اپ خودش تشخیص می‌ده آفلاینی یا نه و هشدار مخصوص نشون می‌ده. بقیه‌ی ابزارها کاملاً آفلاین کار می‌کنند.
- رمزنگاری متن با AES-256-GCM واقعی (از طریق Web Crypto API مرورگر) انجام می‌شود و برای اطلاعات حساس هم قابل‌اعتماده؛ فقط توجه کن که اگر رمز عبورش رو فراموش کنی، هیچ راهی برای بازیابی متن وجود نداره. اگه تاریخ انقضا هم فعال باشه، بعد از اون تاریخ حتی با رمز درست هم متن باز نمی‌شه.
- محاسبه‌ی «مهریه» فقط برای مهریه‌ی سکه‌ای (امامی/بهار آزادی/نیم/ربع سکه) است و بر پایه‌ی قیمت روزی که خودتان در تنظیمات وارد می‌کنید محاسبه می‌شود؛ برای مراحل قانونی و اجراییات رسمی باید از منابع رسمی استعلام گرفت.
- جدول «مورس فارسی» طوری طراحی شده که هر حرف فارسی کد یک حرف لاتین را قرض می‌گیرد (استاندارد رایج بین‌المللی برای الفبای غیرلاتین)؛ برای تبدیل درست، حتماً زبان مناسب را قبل از تبدیل انتخاب کنید.
- تاریخ‌های مناسبت‌های قمری (عید فطر، عاشورا، اربعین و…) بر اساس تقویم هجری قمری تبدیلی و تقریبی محاسبه می‌شن و ممکنه با اعلام رسمی رویت هلال یک روز تفاوت داشته باشن.
- «حالت مرور خصوصی موقت» فقط از ثبت‌شدن تاریخچه/آمار جلوگیری می‌کنه؛ داده‌های اصلی اپ (بودجه، چک‌لیست، اشتراک‌ها و…) رو تحت تأثیر قرار نمی‌ده و هیچ‌جا ذخیره‌ی این وضعیت باقی نمی‌مونه (با هر بار باز شدن اپ، خاموش شروع می‌شه).
